TITLE: Throw TnT
DESC: Throwing tnt by right click / long press
TAG: weapon,technique

TEXT: This 10 command block setup will let you throw tnt by just right click / hold / interact

All you need to do is prepare 10 command blocks
1 repeat
9 chain

H1: ITEM

CMD:CHAT
/give @s tnt 1 10

TEXT: Run this command in chat to get a tnt with the data of "10"
The data value is needed to differentiate it with normal tnt

H1: COMMAND BLOCKS

CMD:R:NR:U:0
/execute as @a[hasitem={item=tnt, location=slot.weapon.mainhand, data=10}] at @s unless entity @e[name=tnt] run summon armor_stand tnt
CMD:C:AA:U:0
/effect @e[name=tnt] invisibility infinite 1 true
CMD:C:AA:U:0
/execute as @a at @s positioned ~~1.3~ run tp @n[name=tnt] ^^^
CMD:C:AA:U:0
/execute as @a unless entity @s[hasitem={item=tnt, location=slot.weapon.mainhand, data=10}] at @s run kill @e[name=tnt, r=5]
CMD:C:AA:U:0
/execute as @e[name=tnt, hasitem={item=tnt, location=slot.weapon.mainhand, data=10}] at @s as @p at @s anchored eyes run summon tnt ^^^1 ~~
CMD:C:AA:U:0
/execute as @e[name=tnt, hasitem={item=tnt, location=slot.weapon.mainhand, data=10}] at @s run playsound firework.launch @a ~~~
CMD:C:AA:U:0
/replaceitem entity @e[name=tnt] slot.weapon.mainhand 0 air
CMD:C:AA:U:0
/execute as @e[type=tnt, tag=!land] at @s run tp ^^^1 facing ^^-1^20 true
CMD:C:AA:U:0
/execute as @e[type=tnt] at @s unless block ^^^0.707 air run tag @s add land
CMD:C:AA:U:0
/execute at @e[type=tnt, tag=!land] run particle minecraft:explosion_particle

TEXT: Now, all you need to do is right click to launch the tnt

Have fun :D
