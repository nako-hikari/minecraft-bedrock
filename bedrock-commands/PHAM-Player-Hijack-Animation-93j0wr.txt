[link][SEE (Stop Expression Editor)](https://azizanzz0.github.io/Image/Websife.html)

TEXT: serves as a 3D animation and posing tool for a block based character model. Its primary purpose is to help users visually create animations and automatically generate the complex mathematical code needed for custom game setups. The application features a split interface with an animation configuration panel on the left and a 3D viewport on the right.[[br]]

TEXT: Users can add specific body parts or bones to animate, such as the head, body, arms, and legs. For each bone, users can create multiple animation keyframes by setting the start time, duration, starting value, target value, and choosing from a wide variety of easing functions like linear, bounce, or elastic curves. To speed up the animation process, the tool includes toggles to automatically mirror the movements of the arms and legs.[[br]]

TEXT: The 3D viewport offers two main viewing modes. The Live Preview mode allows users to watch their created animation loop in real time with play and pause controls. The Axis Editor mode provides interactive 3D gizmos that let users manually rotate and move individual body parts, displaying the exact numerical values for each axis to help with precise posing. Additionally, the application includes a custom skin function where users can upload an image file to change the character texture or reset it to the default look. Finally, as users adjust the keyframes or mirror settings, the tool automatically compiles all the data into a text box at the bottom, generating a final Stop_Expression code that can be copied and used directly in external projects.
